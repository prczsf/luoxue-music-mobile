# 版本更新说明 · v1.10.0

> 面向用户的发布说明，正式条目（精简版）已写入 `CHANGELOG.md` 的 `## [1.10.0]`，本文为详尽版。
> 版本号 `1.10.0`、发布日期 `2026-10-16`；覆盖范围：提交 `91bd4d9` → 本次发布（只看最终结果）。

本次更新是一次较大的功能版本：新增「随心漫游」页与「我的下载」页，补齐了全站下载能力，并重做了我的歌单、歌单管理与播放详情页的若干交互。

## 新增

### 随心漫游（侧边栏新入口）

一句话：一键让本地与在线歌曲随机接着播，不用自己挑歌。

- **全部歌曲**：从你的歌单里随机挑歌起播，卡片上直接显示「来自 X 个歌单 · 共 Y 首」；再点一次即「换一批」。
- **常听歌手**：按常听程度列出歌手，点一下只听这个歌手；点「一起听」可勾选多位歌手混着听。联网时会自动帮你补充更多该歌手的歌，网络不佳也不影响已有歌曲播放。
- **熟歌热歌**：把常听的老歌与榜单新歌混在一起播，底部三档可选：保守（80% 老歌）/ 均衡（70%，默认）/ 探索（50%），切换只影响后面接着播的歌。
- **风格盲盒**：8 个风格色块——摇滚现场、轻音写代码、华语怀旧、ACG 二次元、民谣故事、欧美流行、爵士R&B、全网真随机，点一下就从对应风格里拉歌播放；网络开小差时会自动回到本地歌曲继续播，并给出提示。
- **播放列表**：竖屏点播放栏上的列表按钮、横屏在漫游页右侧，可以看到「最近听过」「正在播放」「接下来播放」；对不想听的歌点「不想听」会立刻换一首补上，也可以选择「不再播放」让这首歌以后都不再出现；面板顶部可「结束漫游」。
- **选择歌单**：页面右上角可勾选「不参与漫游的歌单」，设置会被记住。
- **听歌时随时知道在听什么**：播放栏与播放详情页会显示来源，如「漫游 · 陈奕迅」或「漫游 · 全部歌曲」；点播放详情页的来源可回到漫游页。
- **首次启动默认进入随心漫游页**，侧边栏顺序也做了调整（随心漫游、我的下载加入其中）。

### 我的下载（侧边栏新入口）

- 进入即扫描下载目录，歌曲按文件名先快速上屏，随后自动补全歌手、封面等信息。
- 支持「播放全部」、点单曲播放、按歌名 / 歌手 / 文件路径搜索、下拉刷新与「重新扫描」。
- 每首歌右侧菜单支持：**添加到歌单**、**删除本地音频**（删除前二次确认）。
- 每行显示格式标签（如 MP3 / FLAC）与歌手；目录为空时会显示当前下载目录并给出提示。

### 下载能力补齐

- **播放详情页新增下载按钮**（横屏、竖屏都有），在线歌曲可直接下载到设定目录。
- **歌曲列表新增「下载」「选择音质下载」菜单项**：搜索、榜单、在线歌单等列表的单曲菜单可直接下载，本地歌单详情页同样支持，并支持多选后批量下载。
- 设置 - 下载 新增 **「下载前总是询问音质」** 开关（默认关闭）：开启后每次下载都会先弹音质选择框，关闭则直接按默认下载音质下载。

### 下载可自动写入封面、歌词等元数据（设置 - 下载）

- 设置里的「下载」页新增 **元数据**、**额外文件**、**下载任务** 三组开关，默认全部关闭：
  - **内嵌封面**：把封面写进音频文件，系统音乐播放器也能显示专辑图。
  - **内嵌歌词 / 翻译 / 罗马音 / LX 逐字歌词**：把歌词一并写进文件；逐字歌词为 LX 私有格式，只有本 App 能识别。
  - **同时保存 .lrc 歌词 / .jpg 封面**：在同目录额外生成伴生文件，方便其它播放器读取。
- 新增 **「下载并发数」**（默认 3，可选 1~6）与 **「自动切换音源」**（默认开启）：拿不到目标音质时会自动降级并在提示里说明；关闭后严格按下单音质下载。
- 「我的下载」页顶部新增 **下载任务面板**：显示等待中 / 下载中（实时进度与速度）/ 失败（可单条重试），支持单条取消、全部取消与清除已完成。
- **批量下载先确认再排队**：单次上限 200 首，目录中已有同名歌曲自动跳过，完成后提示「已加入 N 首，跳过 M 首」。
- 下载中的任务会被记住：App 重启后自动重新排队（不支持断点续传，会从头下载），已下载完成的不会重复下载。
- 封面与歌词写入失败不影响音频：音频永远会被保存，失败项只在提示里合并告知。

## 优化

- **我的歌单页改版**：顶部把「我喜欢」「默认列表」做成置顶卡片，下面是自建歌单分区并显示数量；卡片带封面、歌曲数与更新时间。没有自建歌单时直接给出「新建歌单 / 导入歌单」引导。
- **歌单管理更清楚**：长按或点「⋮」改为底部弹层，操作项带图标，删除用红色标注；内置列表不再出现用不上的「重命名 / 删除 / 上移下移」。
- **歌单详情页信息更全**：顶部显示歌曲数量与总时长（如「32 首 · 约 2小时15分」），「播放全部」按钮带歌曲数；新增多选入口，播放、搜索、回到顶部按钮更好点。
- **播放详情页更易跳转**：标题下方显示歌手与来源歌单小胶囊，点一下即可跳到该歌单并定位到正在播放的这首歌；漫游状态下则回到漫游页。
- **下载更不容易失败**：目标音质拿不到时会自动降级到 128k 并提示，遇到无链接会自动换个来源再试；同名文件直接覆盖，不再报错；正在下载中的歌曲重复点击会提示「正在下载中...」，成功 / 失败都有明确的歌曲名提示。
- **收藏在线歌单更快生效**：收藏后立即出现在「我的歌单」，随后在后台静默补齐完整歌曲，不会再出现「0 首」或详情为空。
- **歌单信息自动刷新**：歌曲增删后，歌单卡片上的歌曲数、封面、更新时间会同步更新。
- **独立页面顶部栏统一**（歌单管理、歌单详情等独立页面）：统一与首页同高同宽，修复了标题被裁、与状态栏重叠的问题。

## 修复

- 修复播放详情页下载失败的问题（含换源与音质降级重试）。

- 修复获取到已失效直链（服务端返回 410 / 403 等）时下载失败的问题：现在会自动换链接重试，仍失败才提示该链接已失效。
- 修复下载时内嵌标签写入失败的问题（临时文件缺少扩展名，导致标签解析器无法识别容器格式）。
- 修复下载时内嵌封面写入失败的问题（封面「小图直出」时原图被当作临时文件删除，导致写入失败）。
- 修复冷启动后直接进入随心漫游无法起播、提示「歌单里没有可播放的歌曲」的问题。
- 修复歌单详情页点击歌曲偶发无响应的问题（不再受首页滑动状态影响）。
- 修复收藏在线歌单时的重复判断与并发导致的收藏异常。
- 修复空歌单点播放静默无反应的问题，现在会明确提示「歌单为空，先添加歌曲吧」。

## 兼容与说明

- 本地已有歌单、收藏与「不再播放」记录都会保留；新增的「不参与漫游的歌单」默认为空（全部歌单都参与）。
- 「下载前总是询问音质」默认关闭，与旧版本下载行为一致；升级后仍使用你已设置的默认下载音质。
- 下载中的同名文件会被直接覆盖，请留意下载目录内已有文件。
