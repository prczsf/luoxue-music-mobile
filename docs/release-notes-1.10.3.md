# v1.10.3 发布说明（2026-11-19）

## 核心改进

1. **修复车机方向盘 / 蓝牙「下一首」按键在无法播放歌曲时失效**：
   - 修复切歌/报错窗口下 `MediaSession` 未激活或状态被写入 `STATE_NONE(0)` 的问题（JS 元数据同步 + `dependencies-patch.js` 原生补丁）。
   - 手动/方控切歌立即取消在途重试，防 `setStop()` 竞态中断与连续失败停死。
2. **补全失效源 / 播放期错误自动跳下一首链路**：
   - 修复 `handleLoadstart` 误拦截导致 8 秒起播超时不生效的问题。
   - 统一 2 秒自动切歌计时器并带代际保护，避免连跳两首。
   - 播放期二次失败/超时同步标记不可播放并清理缓存，解决单曲循环死循环。
   - 校验自定义源空 `url`，增加连续 5 首临时网络故障熔断提示。
3. **新增歌单「清理失效歌曲」功能与车机防误退开关**：
   - 新增 `@play_failure_stats` 持久化台账与歌单清理预览弹窗（`count >= 3`）。
   - 新增「收到停止指令时仅暂停（车机防误退）」设置项（默认关闭，手机日常使用不受影响）。
