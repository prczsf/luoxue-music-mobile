### 新增

- 新增「随心漫游」页：一键随机接着播本地与在线歌曲，支持全部歌曲、常听歌手、熟歌热歌（保守 / 均衡 / 探索）、风格盲盒，并可在播放列表中「不想听 / 不再播放」，首次启动默认进入该页
- 新增「我的下载」页：进入即扫描下载目录、自动补全歌手与封面，支持播放全部、搜索、下拉刷新、重新扫描，以及添加到歌单、删除本地音频
- 补齐全站下载能力：播放详情页新增下载按钮，搜索 / 榜单 / 在线歌单 / 本地歌单的歌曲菜单新增「下载」「选择音质下载」，并支持多选后批量下载
- 新增下载元数据写入（设置 → 下载）：内嵌封面、内嵌歌词 / 翻译 / 罗马音 / LX 逐字歌词，可选同时生成同名 .lrc、.jpg 伴生文件，默认全部关闭
- 设置 → 下载新增下载并发数（默认 3）、自动切换音源（默认开启）与「下载前总是询问音质」（默认关闭）
- 「我的下载」页新增下载任务面板：显示等待中 / 下载中（实时进度与速度）/ 失败，支持单条重试、单条取消、全部取消与清除已完成；下载中的任务在应用重启后会自动重新排队
- 批量下载先确认再排队：单次上限 200 首，目录内已有同名歌曲自动跳过，完成后提示加入与跳过数量

### 优化

- 我的歌单页改版：内置「我喜欢」「默认列表」置顶卡片，下方为自建歌单分区并显示数量，空列表时给出新建 / 导入引导
- 歌单管理改为底部弹层，操作项带图标、删除标红，内置列表不再显示用不上的重命名 / 删除项
- 歌单详情页新增歌曲数量与总时长、多选入口与回到顶部按钮，「播放全部」显示歌曲数
- 播放详情页标题下方显示歌手与来源歌单胶囊，点击可跳转歌单并定位到正在播放的歌曲；漫游状态下回到漫游页
- 下载成功率提升：目标音质不可用时自动降级并提示，拿不到链接时自动换源重试，同名文件直接覆盖，重复点击会提示「正在下载中...」
- 收藏在线歌单立即出现在「我的歌单」，随后在后台静默补齐完整歌曲，不再出现 0 首或详情为空
- 统一独立页面的顶部栏高度与宽度，修复标题被裁、与状态栏重叠的问题
- 歌单信息自动刷新：歌曲增删后，歌单卡片的歌曲数、封面与更新时间会同步更新

### 修复

- 修复获取到已失效直链（如服务端返回 410 / 403）时下载失败的问题，现在会自动换链接重试，仍失败才提示该链接已失效
- 修复下载时内嵌标签写入失败的问题（临时文件缺少扩展名导致标签解析器无法识别）
- 修复下载时内嵌封面写入失败的问题
- 修复播放详情页下载失败的问题（含换源与音质降级重试）
- 修复冷启动后直接进入随心漫游无法起播、提示「歌单里没有可播放的歌曲」的问题
- 修复歌单详情页点击歌曲偶发无响应的问题
- 修复收藏在线歌单时的重复判断与并发导致的收藏异常
- 修复空歌单点击播放静默无反应的问题，现在会明确提示「歌单为空，先添加歌曲吧」
